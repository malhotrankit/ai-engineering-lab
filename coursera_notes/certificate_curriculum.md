# IBM RAG and Agentic AI Professional Certificate - Curriculum Snapshot

Source captured: 8 August 2026

This records the ten-course Coursera curriculum supplied by the learner. It is curriculum context, not a claim that every advertised skill is complete or required for the portfolio.

## Course 1 - Develop Generative AI Applications: Get Started (10 hours)

- GenAI and LangChain fundamentals, prompt engineering, and in-context learning.
- Prompt templates, chains, and agents in LangChain.
- GenAI web application work using Flask and JSON output parsing.
- Language-model comparison and selection for use cases.

Status: complete.

## Course 2 - Build RAG Applications: Get Started (7 hours)

- Practical Retrieval-Augmented Generation foundations.
- Interactive RAG interfaces using Gradio.
- LlamaIndex concepts and comparison with LangChain.
- RAG applications using LangChain and LlamaIndex in Python.

Status: complete.

## Course 3 - Vector Databases for RAG: An Introduction (9 hours)

- Vector databases versus traditional databases.
- ChromaDB collections plus update, delete, and management operations.
- Similarity search manually and with ChromaDB.
- Recommendation systems using vector similarity.
- Key internal mechanisms used by RAG systems.

Status: in progress; current single focus.

## Course 4 - Advanced RAG with Vector Databases and Retrievers (8 hours)

- RAG applications with vector databases and advanced retrieval patterns.
- FAISS, ChromaDB, and indexing algorithms such as HNSW.
- Advanced retrievers using LlamaIndex and LangChain.
- Integrated RAG applications using LangChain, FAISS, and Gradio.

Status: not started.

## Course 5 - Build Multimodal Generative AI Applications (8 hours)

- Multimodal concepts and challenges across text, speech, images, and video.
- Models/frameworks including IBM Granite, Meta Llama, Whisper, DALL-E, and Sora.
- Multimodal chatbots and image/video generation using watsonx.ai, Hugging Face, Flask, and Gradio.

Status: not started; optional breadth in the current job-focused critical path.

## Course 6 - Fundamentals of Building AI Agents (11 hours)

- Agents that reason and perform tasks.
- Tool calling and chaining for structured workflows.
- Built-in LangChain agents for data analysis, visualization, and database queries.
- Prompt-engineering and tool-calling practices for agent performance.

Status: not started.

## Course 7 - Agentic AI with LangChain and LangGraph (11 hours)

- Agentic systems with memory, iteration, and conditional logic.
- Reflection, Reflexion, and ReAct architectures.
- Agent orchestration and collaborative multi-agent systems.
- Agentic RAG with routing and retrieval-enhanced reasoning.

Status: not started.

## Course 8 - Agentic AI with LangGraph, CrewAI, AutoGen and BeeAI (13 hours)

- Selecting agentic frameworks and architectural patterns.
- Agentic workflow patterns with LangGraph.
- Structured multi-agent workflows with CrewAI.
- BeeAI applications and AG2/AutoGen conversation-driven interactions.

Status: not started; optional framework breadth in the current critical path.

## Course 9 - Build AI Agents using MCP (10 hours)

- MCP architecture, components, use cases, and differences from traditional APIs/tool calling.
- FastMCP servers with tools, resources, and prompts, including RAG integration.
- MCP clients connecting to single or multiple servers via STDIO and Streamable HTTP.
- Secure interactive workflows using sampling, roots, and permission-based user approval.

Status: not started.

## Course 10 - RAG and Agentic AI Capstone Project (14 hours)

- Design and implementation of an AI system from data through deployment.
- Unstructured and multimodal data transformed into structured JSON using LLMs.
- Multimodal vector databases and multi-agent systems for recommendations.
- MCP server/client integration for tool-augmented agents.

Status: not started. Relevant capstone requirements should be adapted into the existing financial project rather than creating an unrelated portfolio project.
